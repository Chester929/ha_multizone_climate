### Safety: Event Loop Prevention

```python
# Coordinator marks BEFORE change
coordinator.last_update = now()
coordinator.last_value = 22.5

# Set temperature
await set_temperature(22.5)

# B1 event listener checks
time_diff = event.time - coordinator.last_update
if time_diff < 2s:
    # Coordinator change, ignore
    return  # No loop! ✅
```
