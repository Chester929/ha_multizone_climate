# Changelog

All notable changes to this add-on will be documented in this file.

## [1.0.0] - 2026-01-15

### Added
- Initial release of Multizone Climate add-on
- Redis server for state management
- Custom integration auto-installation
- Support for multiple architectures (amd64, armv7, aarch64, i386)
- Configuration flow for easy setup
- Multi-language support preparation (EN)
- Comprehensive documentation

### Features
- Main climate entity management
- Zone-based climate control
- Automatic valve management
- Safety features (minimum valves open)
- Redis-backed state persistence
- Background job processing
- Configurable timing and thresholds
