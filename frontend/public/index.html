About This System

This is the Multizone Climate Control System frontend. The system uses a containerized microservices architecture with separate containers for logic (Go), frontend (TypeScript), and optional MQTT middleware.

Key Features: Main target temperature calculation, intelligent valve management, safety checks, background job processing, and Home Assistant integration.
